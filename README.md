# ✈️ Airline Passenger Satisfaction Analysis

## 📌 Project Overview

This project analyzes airline passenger data to understand the factors that affect customer satisfaction. The analysis was completed using Microsoft Excel with data cleaning, Pivot Tables, charts, and an interactive dashboard.

The project helps identify passenger satisfaction patterns based on customer type, travel type, class, age, flight distance, and airline services.

-----
**Data source:** https://www.kaggle.com/datasets/saicharankomati/dataco-supply-chain-dataset

## 🎯 Project Objectives

- Analyze overall passenger satisfaction.
- Compare satisfied and dissatisfied passengers.
- Understand how customer type affects satisfaction.
- Analyze passenger satisfaction based on travel type and flight class.
- Identify the impact of airline services on customer satisfaction.
- Study passenger details such as age and flight distance.
- Present important insights using an interactive Excel dashboard.

## 🔄 Project Process

1. Imported the airline passenger dataset into Microsoft Excel.
2. Checked the dataset for missing values and duplicate records.
3. Cleaned and prepared the data for analysis.
4. Organized the data for analysis.
5. Created Pivot Tables to summarize passenger information.
6. Created Pivot Charts to visualize satisfaction patterns.
7. Designed an interactive dashboard.
8. Used filters and slicers to make the dashboard easy to explore.

---

## 📈 Dashboard Insights

The dashboard helps analyze:

- Total number of passengers
- Overall passenger satisfaction
- Satisfied and dissatisfied passengers
- Satisfaction based on customer type
- Satisfaction based on travel type
- Satisfaction based on flight class
- Passenger satisfaction across different age groups
- The relationship between airline services and customer satisfaction

---

## 💡 Key Findings

- Passenger satisfaction varies based on travel type and flight class.
- Customer experience and service quality have an important impact on satisfaction.
- Inflight services such as Wi-Fi, entertainment, seat comfort, and cleanliness influence passenger experience.
- Business travel and personal travel passengers may have different satisfaction levels.
- The dashboard makes it easier to identify patterns and compare passenger groups.
